# 0002: Five-page discovery fixture and modular build contracts

Accepted starting point, 30 September 2026.

The user requested separate About and Contact pages, an optional demo and a platform with plugins and broad AI integration. Start with a fictional Home, Services, Products, About and Contact site rather than using live business content. Keep it in a separate demo project with explicit development opt-in and no persistent initialization.

Implement common content/source contracts and build validation, renderer and export contributor seams in the core. Freeze output after contributions and include all files in artifact identity. Persistent CMS selection remains open; the fixture enables the same representative scenario to be evaluated across candidate engines.

Preview, deployment, scoped AI operations and component/module registration remain planned contracts. Trusted compiled extensions and AI website credentials are different access mechanisms. A plugin marketplace and hot-loading are deferred; modularity itself is required from the beginning.

Compared with a disposable single-page test, the fixture covers navigation, shared layout, images, repeated cards and multiple business page types, and can later support optional onboarding. Compared with choosing a CMS first, it gives candidate engines a concrete model and behavior to prove.
